# Valo Managed IT Services
[See it here](https://valo-msp-port.kumiko-d15.workers.dev)
A static portfolio website for a fictional St. Louis managed IT services company.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

No database, authentication, API, or external backend is required. The contact form is a demo and the IT assessment runs entirely in the browser.
